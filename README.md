# Bancos de Dados MySQL — Estudos

> **Categoria:** Banco de dados · **Tecnologia:** MySQL / SQL

Repositório de estudos de modelagem relacional e construção de estruturas SQL para três domínios de exemplo: **AUTOPRIME**, **FASTBITE** e **LOGISTRUCK**.

## Arquivos

- `AUTOPRIME` — scripts para domínio automotivo (funcionários, clientes, veículos, estoque, serviços e relacionamentos).
- `FASTBITE` — estudo de banco de dados para serviço de alimentação.
- `LOGISTRUCK` — estudo de banco de dados para logística.

## Como estudar

1. Abra o arquivo correspondente ao domínio desejado.
2. Revise as instruções SQL e as dependências entre tabelas.
3. Execute comandos no MySQL Workbench ou outro cliente compatível **somente em um banco de testes**.

> **Atenção:** alguns scripts contêm `CREATE`, `ALTER` e outras instruções que modificam estruturas. Confira o banco selecionado antes de executar. Os scripts não foram validados como migrações prontas para produção.
